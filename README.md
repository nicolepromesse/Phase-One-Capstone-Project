# IgirePay Payment Gateway Project

## Overview
IgirePay is a secure digital wallet and payment management system inspired by mobile money platforms.

The system allows users to:
- Create accounts
- Deposit money
- Withdraw money
- Transfer money
- View transaction history
- Prevent duplicate transactions using unique reference IDs

## Technologies Used
- Java
- JavaFX
- JDBC
- PostgreSQL
- Maven
- Git & GitHub

## Project Structure
- model
- dao
- service
- util
- console
- javafxui

## Features
- Wallet accounts
- Savings accounts
- Transaction processing
- Duplicate transaction prevention
- Authentication using PIN
